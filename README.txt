# Student Analytics Dashboard

A simple academic project combining Descriptive Analytics, Design Thinking and Agile methodology.

## How to run
1. Open `index.html` in Google Chrome or Microsoft Edge.
2. Use the subject and attendance filters.
3. The charts update automatically.

## Project presentation
- Problem: Teachers need an easy way to understand student performance and attendance.
- Descriptive Analytics: averages, distributions, comparisons and trends.
- Design Thinking: Empathize, Define, Ideate, Prototype, Test.
- Agile: develop the project in short sprints and improve it using feedback.

The data in this prototype is sample data for demonstration.
